// Manifesto

How we learn and build together. Open collaboration, real code, and a team behind every commit.

  1. 01

    Learn by shipping

    No toy tutorials or abandoned roadmaps. We build real tools together from day one, with peers who review your code and help you grow.

  2. 02

    Zero gatekeeping

    It does not matter what college you attend or where you start. If you want to build and collaborate, you belong here.

  3. 03

    Build in the open

    Every line, issue, and discussion is public. You see how real software is designed, argued, tested, and shipped.
